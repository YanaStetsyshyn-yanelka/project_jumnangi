# project_jumnangi
terminal game
1. Зберігання даних (Словники та Списки)

Словник (dict): Ми створили один великий словник state (у функції create_state()), де лежить все: ХП, гроші, клас, булеві змінні (наприклад, have_key: False). Ми передаємо його з локації в локацію.

Списки (list): Використовуємо для бази загадок (RIDDLES), інвентарю (inventory) та для збереження загадок, які вже були (used_riddles).

2. Умови та Цикли

while True: Використали для всіх меню вибору (щоб код питав "Ваш вибір:", поки гравець не введе нормальну цифру) та для боїв (бій йде, поки ХП гравця або боса > 0).

if/elif/else: Основна логіка гри. Наприклад, перевіряємо, чи є в інвентарі потрібний предмет (if "Деревина" in state["inventory"]), чи вистачає грошей на покупку і чи правильна відповідь на загадку.

Цикл for: Використали, щоб виводити список предметів з інвентарю.

3. Рандом і фільтрація

Модуль random: Використали random.choice(), щоб випадково вибирати загадку зі списку.

Генератор списків (List comprehension): Конструкція [r for r in RIDDLES if r not in state["used_riddles"]] — використали її, щоб на льоту створювати список лише з тих загадок, які гравець ще не відгадував.

4. Збереження результатів (Робота з файлами)

Запис (mode="a"): Функція save_result() відкриває текстовий файл results.txt і дописує в кінець рядок з результатом (ім'я, клас, залишок ХП).

Читання (mode="r"): На старті гри ми зчитуємо цей файл і виводимо останні 5 проходжень.

try/except FileNotFoundError: Поставили цю "заглушку", щоб гра не вилітала з помилкою при найпершому запуску, коли файлу results.txt ще фізично не існує.

5. Структура (Функції)

Ми не писали код "простирадлом". Всі локації (forest, desert, mountains, volcano, temple) і механіки (choose_class, final_boss) винесені в окремі функції def. Головна функція main() просто викликає їх по черзі.

6. Форматування

f-рядки: Використовували, щоб вставляти змінні прямо в текст (наприклад, f"Гравець: {state['name']}").

коди: Коди типу \033[31m для розфарбовування тексту (червоний, зелений, жовтий) прямо в консолі.

Багаторядкові принти ("""): Щоб зручно малювати менюшки та рамки локацій без купи окремих print().
